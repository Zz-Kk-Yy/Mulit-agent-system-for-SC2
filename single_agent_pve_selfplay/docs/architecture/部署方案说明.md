# SwarmBrain 工程结构与部署方案

仓库按 **根目录（入口/文档）+ 两个自包含模式包** 组织：

| 路径 | 场景 |
|------|------|
| 仓库根目录 | README、`.env`/`requirements.txt`、快捷启动脚本、`docs/`、`scripts/` |
| [`single_agent_pve/`](../../single_agent_pve/) | 单一 SwarmBrain vs 电脑/人类 |
| [`multi_agent_duel/`](../../multi_agent_duel/) | 红蓝双 Bot + 双侧 DeerFlow |

根目录**不再保留**与模式包重合的运行时文件（如 `swarmbrain.py`、`dashboard/`、`mcp_server/` 等）。

## 启动

```powershell
.\run_single_agent_pve.ps1
.\run_multi_agent_duel.ps1
```

## 校验根目录是否干净

```powershell
python scripts\reorganize_project.py
```
